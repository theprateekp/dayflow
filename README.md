# Dayflow

Dayflow is a calm daily-life copilot for turning scattered tasks and routines into one clear next move.

## Product loop

- **Today:** see the next useful action, capture new tasks, and complete work with lightweight feedback.
- **Routines:** maintain repeatable anchors without treating missed days as failure.
- **Reflect:** review momentum and use gentle prompts to carry the helpful parts forward.

## Tech

- Expo SDK 54
- React Native 0.81
- Expo Router 6
- TypeScript
- NativeWind
- AsyncStorage for local-first persistence

## Run locally

```bash
pnpm install
pnpm dev
```

The app is configured for web preview through Metro and native iOS/Android builds through Expo.

## Branding

The product is branded as Dayflow with a custom green / warm-neutral visual system. There is no Manus branding in the user-facing app metadata or UI.
